Identity

The SDK forwards a host-signed JWT with every API call. In production your server mints it (see docs/embedding.md) — signing in the browser, like this page does, is for local development only. The default secret matches deploy/.dev.vars.example, so on wrangler dev it just works.

Hint elements

Inline custom elements shipped in /sdk.js — drop them where users hit a gap. Docs: docs/hints.md.

<chalk-hint> — link · button · card 
<chalk-hint label="Missing a report? Tell us" topic="reports"></chalk-hint>
<chalk-hint variant="button" label="Suggest an improvement" topic="menu"></chalk-hint>
<chalk-hint variant="card" label="Can't find an integration?"
            description="Tell us which tools you want connected."
            topic="integrations" prefill-title="Integrate with "></chalk-hint>
<chalk-topic> — live count, opens the board filtered 
<chalk-topic topic="menu" label="open ideas for the menu" cta-label="vote or add yours"></chalk-topic>
<chalk-topic topic="reports" status="open,planned,in_progress,under_review"
             label="active ideas for reports" cta-label="have your say"></chalk-topic>
Counts come from GET /api/v1/posts/count and cache in sessionStorage for 5 minutes.
<chalk-post> — vote card for one idea 
<chalk-post post="bulk-edit-menu-items" cta-label="Vote for this"
            voted-label="You're on the list ✓"></chalk-post>
With a JWT it votes in place (Tessa has already voted — sign in as her to see the voted state). Anonymous visitors get the post overlay instead.

Overlay

Chalkboard('open', …) slides the board in from the right. ESC, the backdrop, or the board's close button dismiss it. 

Chalkboard('open', { page: 'submit', topic: 'reports', prefillTitle: 'CSV export of ' });
Chalkboard('open', { page: 'board', topic: 'menu' });
Chalkboard('open', { page: 'post', postId: 'bulk-edit-menu-items' });

Inline embed

Chalkboard('embed', …) mounts the board chrome-less in an auto-resizing iframe. 

Chalkboard('embed', {
    url: window.location.origin,
    container: '#embed-target', // or omit: [data-feedback-embed]
    initialPage: 'Board' // 'Board' | 'Roadmap'
});

Theming

Hint elements read inheritable --chalk-* custom properties through their shadow roots — scope them to a container to re-theme a surface. 

.themed-zone {
    --chalk-brand: #0d9488;
    --chalk-radius: 999px;
}

Events

Every interaction calls the onEvent callback and batches to POST /api/v1/events (flushed every 5 s — watch the network tab; staff see the funnel on /staff). Successful actions also dispatch chalk:submitted / chalk:voted DOM events on window.
